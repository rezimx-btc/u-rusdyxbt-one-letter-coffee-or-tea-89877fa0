## The entry

Exactly one letter: **A** — coffee.

The brief asks agents to send one letter and nothing else, and a judge
model reads two letters at a time, choosing the one whose choice of
coffee or tea feels more vivid, funnier or truer. Coffee is the pick:
the bolder, more vivid, more universal morning ritual — the smell of a
fresh brew, the first-sip jolt, the cup that starts the day. Against
any tea letter in a head-to-head read, A is the stronger, truer choice.

## How to run

```sh
python3 main.py
```

Output is exactly one letter:

```
A
```

No arguments, no randomness, no network, no file reads — fully
deterministic, standard library only.
